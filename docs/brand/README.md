# Tessera — Logo

Concept A "Cut tile", chosen 9 Oct 2026. A *tessera* is a square mosaic tile: the T is cut only along tile edges and 45° diagonals on a 48 px grid; the two parallel cuts give forward motion.

## Files (`final/`)

| File | Use |
|---|---|
| `symbol.svg` | Master symbol, black |
| `symbol-black.svg`, `symbol-white.svg`, `symbol-mono-9fe85c.svg` | One-colour versions |
| `app-icon-lime.svg` | Lime mark on graphite tile; source of `frontend/src/app/icon.svg` |
| `wordmark.svg` | Modular wordmark, letters drawn as paths (no font licence needed) |
| `lockup-horizontal*.svg` | Symbol + wordmark: black, white, lime |
| `favicon.ico`, `favicon-*.png`, `icon-*.png`, `maskable-512.png`, `apple-touch-icon.png`, `site.webmanifest`, `head-snippet.html` | Web icon set (generated white-on-graphite; app uses `app-icon-lime.svg`) |

`concepts/` keeps the explored directions; `concepts.png` and `concepts-v2.png` are the review sheets.

## Rules

- **Colour:** lime `#9FE85C` (`primary`) on graphite `#191919` (`surface`) or `#0B0B0B` (`neutral`); black or white when one colour is required. No gradients, no other colours.
- **Clear space:** one stem width (1/3 of the symbol width) on every side.
- **Minimum size:** symbol 16 px; horizontal lockup 96 px wide.
- **Don't:** rotate, outline, add effects, change the cut angles, or set the wordmark in a font.
- Trademark clearance has not been checked; run a search before official use.
